🐘 Docker — Qora Database

Нажмите кнопку, чтобы скопировать команду в исходном формате
docker run --name qora-db -e POSTGRES_USER=qora_admin -e POSTGRES_PASSWORD=Qora_MogS_2026_year -e POSTGRES_DB=qora_main -v qora_db_data:/var/lib/postgresql/data -p 5432:5432 -d postgres:16

⚡ После копирования вставьте команду в терминал (Linux/macOS/Windows WSL) — запустится контейнер PostgreSQL 16 с именем qora-db.

🐘 PostgreSQL 16 | Volume: qora_db_data | Порт 5432
✅ Команда скопирована!
